# OTT Streaming Content Trend Analysis

## Project Overview
This project analyzes OTT streaming content from Netflix, Amazon Prime, and Disney+ Hotstar. The main objective is to identify trends in genre popularity, content ratings, release years, regional distribution, and movie duration.

## Objectives
1. Analyze content distribution across different OTT platforms.
2. Identify the most popular genres.
3. Study content ratings and release trends.
4. Analyze country-wise content distribution.
5. Compare movies and TV shows.
6. Generate useful business insights through data analysis.

## Dataset
The dataset contains 600 records with details such as:
- Content ID
- Platform
- Title
- Content Type
- Release Year
- Date Added
- Country
- Genre
- Content Rating
- Duration
- Number of Seasons

**Note:** The dataset is synthetic practice data created for this project, not official platform data.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- SQL (MySQL / PostgreSQL)
- Google Colab
- Excel

## Project Workflow
1. Collect the OTT content dataset.
2. Load the dataset using Pandas.
3. Perform data cleaning and preprocessing.
4. Handle missing values and duplicate records.
5. Perform Exploratory Data Analysis (EDA).
6. Create visualizations using Matplotlib.
7. Write SQL queries for data aggregation.
8. Identify important trends and insights.
9. Prepare a content strategy report.

## Visualizations
The project includes the following visualizations:

1. Content titles by platform.
2. Movie and TV show distribution.
3. Top 10 popular genres.
4. Content release trends by year.
5. Content ratings by platform.
6. Top 10 countries by content count.
7. Movie duration distribution.
8. Average movie duration by platform.

## SQL Analysis
SQL queries are used to:
- Calculate total titles by platform.
- Compare movies and TV shows.
- Identify popular genres.
- Analyze release-year trends.
- Study content ratings.
- Analyze country-wise distribution.
- Calculate average movie duration.
- Compare TV show seasons.

## Key Business Recommendations

1. **Genre Analysis:** Identify genres with low catalog representation and investigate audience demand before acquiring new content.

2. **Regional Content:** Improve regional content availability using country-wise analysis, subtitles, and dubbing.

3. **Content Duration:** Analyze movie duration and TV show seasons to understand audience viewing preferences.

## Expected Outcomes
- Understanding OTT content distribution.
- Identifying genre and regional trends.
- Improving data analysis and visualization skills.
- Learning SQL aggregation techniques.
- Developing business recommendations using data.

## Conclusion
This project demonstrates how Python, SQL, and data visualization can be used to analyze OTT streaming content. The analysis helps identify content patterns and generate useful recommendations for content strategy and business decisions.
